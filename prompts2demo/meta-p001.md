This application maintains a user's work portfolio, which can be used at a later date for building
resumes or writing a personal essay, etc.

Allow users to add an experience as plain text or Markdown, with the ability to preview the Markdown.

Then use an AI agent to extract key information, including company, type (project or work experience), start date, end date, etc., and properly index it for future use.

First, show the user a preview of the extracted information. Minimize changes to the original content at this stage.

Next, allow the user to ask the AI to augment and improve the experience (portfolio item). Store the final version once the user approves it.

Make sure to search the existing system for similar experiences and identify potential duplicates, providing links to the existing entries.

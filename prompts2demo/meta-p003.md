Create a user story that allows a user to upload a job description. An AI agent should then review each existing portfolio item, evaluate its relevance to the job description, and decide whether to include it in the resume.

The agent should generate a Markdown version of the resume tailored to the job description. It should also improve the descriptions of selected portfolio items to better align with the job requirements, highlighting relevant skills and experience without changing or fabricating facts.

The agent should take into account Applicant Tracking Systems (ATS) and other automated resume-screening tools when optimizing the content, keywords, structure, and formatting of the resume.
